# Reproducibility package — Signed radial-current quantum criterion

- `PROOF_REPORT.md`: exact true-deleted-vacuum current identity, conditional center-cap/deletion consequence, and smooth positive SU(2) rotor counterexample to the necessity of the previous one-sided effective-potential budget.
- `verify_signed_radial_current.py`: deterministic calculations for six analytic class-rotor ground states. Requires NumPy and SciPy. No Monte Carlo.
- `verification.log`: captured output of that verifier.
- `SHA256SUMS.txt`: file checksums inside this archive.

This package does **not** prove the uniform current estimate for the nonlinear Penrose deleted ground state, a regulator-uniform physical spectral gap, or continuum Yang–Mills reconstruction. It does not modify uploaded Penrose Stage 26/Monte Carlo files.
