# Joint high-spin, fixed nonclass fraction, and the cap-selection gate

**Purpose.** This self-contained continuation studies the exact finite SU(2) variational *trial class*, not the fully interacting ground state. It proves simultaneous high-spin/O(sqrt(b)) feasibility, fixed nonclass norm fraction, mutually incompatible target-cap marginals at the same leading energy scale, and a quantitative Ritz-to-cap transfer criterion. It does not prove the Penrose mass gap.

Run each deterministic Python check (NumPy, SciPy):

```bash
python verify_joint_color.py
python verify_cap_transfer.py
python verify_radial_score.py
```

Files `ENERGY_CERTIFICATES.csv`, `CAP_CERTIFICATES.csv`, `COLOR_CAPS.csv` are generated by the scripts; the `*_VERIFY_LOG.txt` and `VERIFY_LOG.txt` contain captured stdout. `PROOF_REPORT.md` gives exact equations and the distinction between theorem, conditional result, and open obligation.
