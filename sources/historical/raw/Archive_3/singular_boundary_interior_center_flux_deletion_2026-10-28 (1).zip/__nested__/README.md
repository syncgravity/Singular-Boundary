# Interior magnetic deletion: center-flux Ward and tangent benchmark

Run `python verify_center_flux_bulk_deletion.py`. Full statements, exact assumptions, limitation and proof appear in PROOF_REPORT.md.

* True finite SU(2) Wilson: any deleted bulk face has an exact center-flux parity symmetry, a positive trace response, and an exact two-state Ritz upper bound.
* Exact Gaussian tangent: any bulk-face deletion increment is bounded by `(3/(2 sqrt(2)))*sqrt(b_f A_f)` independent of face count.
* **Not proved:** the same uniform bound for the nonlinear SU(2) bulk vacuum, extreme-defect rarity throughout the disk, or a mass gap.
