# Reproducible 2+1D Penrose / square SU(2) Wilson study

See **`YM_2P1_CAUSAL_NOTE.md`** for the formulation, calibration, finite-cutoff causal comparison, Monte Carlo results, gauge-invariant temporal correlators, static-source effective energies, and limitations.

## What the package DOES support

- Direct Z^5 rational-slope Penrose periodic cellulations, rather than proximity-inferred graphs.
- Periodic 2+1D SU(2) interacting Wilson gauge theory, dynamically coupling adjacent spatial slices through temporal plaquettes.
- Matched total physical spatial area, common periodic time direction (N_t=10), and equal *mean* spatial and temporal bare Wilson couplings.
- Spatial/temporal plaquette observables; gauge-invariant time-separated rectangular Wilson loops; a connected 0++-candidate scalar correlator.
- Explicit geometric weights, uniform-mean-weight and shuffled-weight counterfactuals, plus an alternative square control approximately matching physical nearest-neighbor source separation.
- Reproducible two-seed Monte Carlo measurements with nominal blocked errors; 12 automated tests including the previous six geometry tests and six new 2+1D tests.

## What the package DOES NOT support

- A numerically established difference in the continuum, renormalized 2+1D Yang–Mills spectrum, string tension or vacuum glueball gap.
- A fully nonperturbatively renormalized matching of physical gauge couplings and anisotropies, or a continuum a→0 trajectory.
- A valid 0++ effective-mass plateau from the noisy unsmeared scalar correlator; short Wilson-rectangle ratios are static-source energies, not glueball gaps.
- Exact length- and density-matching of physical source separations on both inequivalent lattices simultaneously.

## Run

A working environment needs `python >=3.10`, `numpy`, `scipy`, `numba`, `pytest`; `matplotlib` regenerates plots.

```bash
pytest -q test_penrose_causal.py test_penrose_2p1.py
python analyze_2p1.py
python plot_2p1.py
```

For a quick smoke run:

```bash
python penrose_2p1_study.py --M 5 --betas 2.5 --nt 10 --seeds 109 --burn 50 --steps 90 --thin 3 --block 3 --out smoke.json
```

Full run commands are listed in the research note. Monte Carlo runs can take several minutes and depend on the Numba JIT compilation/cpu speed. The numerical JSON files are complete computed outputs from the present session, **not** automatically regenerated by reading the note. The `analyze_2p1.py` script reads output files and regenerates aggregated data.

## Most important interpretation

The finite-lattice geometric-weight model differs clearly between Penrose and square, while replacing Penrose couplings by uniform mean-matched values removes the resolved difference. Shuffling the geometric weights preserves the difference. That is evidence for **discretization/heterogeneous-coupling mediation**, not evidence for a changed universal continuum Yang–Mills excitation gap.
