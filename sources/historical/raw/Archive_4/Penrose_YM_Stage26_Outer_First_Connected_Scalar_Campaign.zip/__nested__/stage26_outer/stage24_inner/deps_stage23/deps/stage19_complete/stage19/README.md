# Stage 19 target-first matched loop pilot

Run `OPENBLAS_NUM_THREADS=1 NUMBA_NUM_THREADS=1 python target_first.py --roots 192 --targets 24 --variants 3 --output pilot` inside this directory. Source checkpoint files must exist as `/mnt/data/square_nt20_seed101.npz` and `/mnt/data/penrose_nt20_seed101.npz`; edit the `fn` path in `target_first.py` if working elsewhere. `python -m unittest -q test_target_first` checks deterministic selection and unequal-face matching.

**Predeclared geometric target family:** physical area `[1.0, 1.4, 1.9, 2.5, 3.2, 4.0]`, perimeter `[4.5, 5.5, 6.5, 8.0, 9.5, 11.5, 14.0]`, excluding combinations with compactness outside `[0.2, 0.85]`. Those target descriptors are chosen before examining either candidate catalogue. The two regulators independently propose closed connected clusters with 2,3,4,5,6,7,8,10,12,15 faces, using deterministic growth variants. Each target is assigned at most one matched pair, and each sampled face root is used at most once per geometry. Differences are scaled in `(log area, log perimeter, compactness)` using fixed scales `(0.25,0.25,0.12)`, with maximum cross-geometry mismatch 1.5. Gauge values are never used for catalogue selection.

**Control preserved:** the original exact full-face-anchor projection for 3-,5-,8-face deterministic loop families is separately measured and written to `full_volume_control` `(20,3)`; the matched subset `(20,1)` is *not* labeled zero momentum and does not replace it. This pilot does not exhaustively sample orientations or reflections, only uses descriptors invariant under orientation reversal. It has no proof of physical equivalence or reliable scalar state overlap. Results on one saved gauge field per geometry provide implementation diagnostics only. The Penrose M55 approximant geometry and physical renormalization limitations remain unchanged.
