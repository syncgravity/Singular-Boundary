# Certified two-prism incidence and nonlinear crossing-action response

## Source boundary
The uploaded `penrose_complete_catalogue.npz` contains indexed cycle records (`idx`, `sign`, `length`, etc.), **not** an edge endpoint table or certified planar rhombus face list. The stage-26 archives contain simulation snapshots, not signed 3D cell data. Thus the present assembly is an **independently constructed abstract two-quadrilateral patch consistent with local edge-adjacent rhombus combinatorics**, not a certified extraction from the project's complete Penrose tiling. To certify the actual tiling one needs the planar vertices, edge endpoint indices, rhombus cyclic vertex lists, temporal gluing and boundary conventions.

## Exact integer cellular certificate
Input oriented quadrilaterals (0,1,2,3) and (2,1,4,5) sharing an oppositely directed edge. Extrude vertices to time layers 0 and 1. Glue identical temporal side faces and edges across the two prisms. The verified resulting complex has 12 vertices, 20 edges, 11 faces, two 3-cells, one shared interior temporal face. Boundary matrices d1 (12x20), d2 (20x11), d3 (11x2) satisfy **d1@d2=0**, **d2@d3=0** exactly, ranks 11, 9, 2. The shared face appears with coefficients (+1,-1). See `verify.py`, `incidence.npz` and `certificate.json`.

## Nonlinear coordinate deformation and Bianchi identity
For a selected oriented link e, fix A in su(2), norm |A|=a, define U'_e=exp(A)U_e and keep every other link fixed. All plaquette holonomies are actual products of links and therefore all nonabelian cell Bianchi identities hold both before and after. Exactly those faces f with d2[e,f] !=0 change; in this two-prism patch no link touches more than 3 distinct faces. At the linearized flat connection, the face-angle variations are d2[e,f] A, so d3.T @ d2.T=0 ensures compatible curvature redistribution. The deformation is not claimed to flatten an arbitrary face while preserving others.

## Exact expectation bound under the interacting undeleted Gibbs law
Let µ0(dU)=Z0^{-1}exp(-S0(U))dU with S0=sum over retained faces f of β_f (1-½Tr W_f), β_f <= c_+ λ. Let T_t be simultaneous fixed left SU(2) rotations U_e -> exp(t A_e)U_e on a selected set J, where each A_e is a *fixed* Lie-algebra element independent of U (and gauge-frame issues can be addressed by choosing a frame; not a gauge-invariant physical map). Haar measure is preserved. The function f(t)=E_{µ0}[S0(T_t U)-S0(U)] obeys f(0)=0 and f'(0)=0 by Haar integration by parts: ∫ directional derivative of exp(-S0) = 0. Each face holonomy is a product of at most L fixed-length factors, so |d²/dt² (β_f d(W_f(T_tU)))| <= C β_f (sum_{e in ∂f∩J}|A_e|)^2. Bounded incidence, bounded L and Cauchy–Schwarz yield |f''(t)| <= C λ sum_{e in J}|A_e|². Hence 0 <= E_{µ0}[S0(T_1U)-S0(U)] <= C λ sum_{e in J}|A_e|². The nonnegativity follows from the equality to relative entropy D_KL((T_1)_*µ0 || µ0), since a Haar-preserving bijection changes no reference entropy. This is a true *actual nonlinear Gibbs* estimate with all undeleted spatial-temporal faces included, independent of volume and cavity geometry. For |A_e| <= M / sqrt(λ), the expected cost is <= C M² |J|, hence O(|J|) independently of the ambient volume.

The result is not a large-field tail and does not show an arbitrary-support repair transport: for a plaquette with order-one initial geodesic angle, a deformation on O(1) edges with |A_e|~λ^-1/2 cannot reduce the angle to O(sqrt(log λ/λ)). Order-one rotations still have only the O(λ |J|) bound. The method also does not independently bound the Jacobian of configuration-dependent repairs.

## Exact general crossing penalty
For any configuration-dependent transform T with boundary-link displacements a_e, let A_f=sum_{e in boundary f} a_e. Then S0(TU)-S0(U) <= Σ_{f retained and touched} β_f( sqrt(2d_f(U)) A_f + (A_f²)/2 ). For small deterministic rotations the averaged first-order term cancels under the Gibbs law as shown above; this cancellation is unavailable without further argument for nonlinear, configuration-dependent large rotations.
