# R3: Exact background-subtracted Wilson activities and a conditional core-event theorem
26 October 2026. Status: finite-block exact constructions and conditional good-staple estimate; no unconditional continuum-uniform polymer convergence or mass gap.

## 1. Exact local Wilson conditional law and good-staple tail
For SU(2), let p(U)=Tr(U)/2. Fix all links except one link U. Each incident Wilson plaquette is of the form β_i p(U C_i) (possibly after inversion, using Tr U=Tr U^{-1}). Identify SU(2) with S^3 unit quaternions; p(UC_i)=u·q_i for a unit q_i in R^4. Thus the one-link conditional density is exactly

  ν(du|ext)= z(k)^{-1} exp(k·u) du,  k=Σ_i β_i q_i, κ=|k|,
  z(κ)=2 I_1(κ)/κ.

For a designated plaquette p0, set q0=q_{p0}; d0=1-u·q0. Let δ in (0,1], r=arccos(1-δ), and suppose κ>0 and angle(k/κ,q0)≤r/2. Spherical triangle inequality yields d0>δ implies angle(u,k/κ)>r/2, so u·k/κ≤cos(r/2)=sqrt(1-δ/2)≤1-δ/4. Since z(κ)≥c e^κ(1+κ)^(-3/2) for κ≥1, integration gives

  ν(d0>δ | ext) ≤ C(1+κ)^(3/2) exp(-κ δ/4), κ≥1.

This is a genuine localized conditional core-event estimate without a geometric buffer. It holds only on the explicitly defined *good-staple alignment* exterior configurations. The estimate does not infer the good-staple event from plaquette defects.

A necessary caution: if an exterior temporal staple is aligned opposite q0 and has strength exceeding β0, then k can point opposite q0; as κ→∞ the conditional law concentrates at u=-q0 and d0→2. Thus the good-staple assumption cannot be discarded, and the conditional core event is NOT uniformly suppressed for arbitrary exteriors.

For any event G measurable with respect to the external links (not U),
  μ({d0>δ}∩G) ≤ C E[1_G (1+κ)^(3/2) exp(-κδ/4)]
if G enforces good alignment and κ≥1. Consequently
  μ(d0>δ) ≤ μ(G^c)+ C E[1_G (1+κ)^(3/2) exp(-κδ/4)].
The bad-staple probability is an independent unsolved problem. For multiple cores, multiplying conditional bounds requires a sequentially valid good-staple condition, including after previous core-event conditioning; no such condition is established here.

## 2. Exact gauge-covariant finite-block integration
For nested finite spacetime regions B_k with retained boundary/coarse link variables Y_k, and internal X_k, define the exact partial integration
  Z_k(Y_k)=∫ exp[-S_k(X_k,Y_k)] dX_k,
  F_k(Y_k)=-log Z_k(Y_k).
For finite compact groups and finite Wilson couplings Z_k>0, so F_k is real analytic. Gauge transformations of retained boundary links conjugate/change variables among integrated links; Haar invariance gives boundary-gauge invariance of Z_k whenever retained variables form a gauge-compatible set. Multi-scale iteration is an identity only if the local actions and cross-block factors are retained exactly (one must not omit couplings crossing block boundaries).

Choose an explicit background gauge action F_k^bg(Y), for example the Wilson action evaluated on a specified gauge-equivariant background interpolation plus its local quadratic/determinant terms (where that construction is defined); set R_k=F_k-F_k^bg. Neither F_k^bg nor the subtraction is presumed to be small. This definition alone gives no localized norm estimates.

## 3. Canonical gauge-invariant ANOVA/Möbius polymer coefficients
Fix a finite retained link set Λ. Let E_A denote Haar conditional averaging of a function over all retained links outside A (for A⊆Λ). Since Haar averaging commutes with the boundary gauge action, E_A maps gauge-invariant functions to gauge-invariant functions. For any continuous real residual R(Y), define
  Ψ_A(Y_A)=Σ_{B⊆A}(-1)^{|A|-|B|} E_B R(Y_B).
Then EXACTLY R(Y)=Σ_{A⊆Λ} Ψ_A(Y_A); E_B Ψ_A=0 whenever A is not a subset of B; and each Ψ_A is gauge invariant under the induced boundary action. If coarse link variables are grouped into cells, use cell variables instead of individual links. Local extraction can be defined unambiguously by F_local=F_bg+Σ_{diam A≤R0} Ψ_A, F_res=Σ_{diam A>R0} Ψ_A. Coefficients are post-integration, background-subtracted and derived from the original Wilson integral.

Norm identity/bound: ||Ψ_A||∞ ≤2^{|A|}||R||∞. It is NOT a useful summable cluster estimate: it provides no decay with diam A, does not control the number of A and generally grows with cutoff. Connected polymer grouping must be proved using decay/cumulant bounds, rather than declaring arbitrary ANOVA components connected.

For source insertions O_i, ∂_{t_1}...∂_{t_n} log Z_k(Y;t)|_{t=0} equals their conditional connected cumulant; the same E_A and Möbius operation yields exact spatially supported connected-source coefficients. Their rooted norms remain uncontrolled.

## 4. A valid conditional rooted activity criterion
If actual residual connected polymers Γ generated by a specified block factorization satisfy
  sup_z Σ_{Γ∋z} |w_k(Γ)|exp((α+1)|Γ|+m diam Γ) ≤ ε
with ε small enough for the compatibility graph's Kotecký–Preiss criterion, then the corresponding polymer partition-function series converges. This is a conditional theorem only. An event-probability tail bound alone does not prove an activity estimate; post-integration fluctuation determinants, background propagation, all loop characters and overlap factors must be bounded.

## 5. What must be proved next
(a) Probability of bad-staple misalignment conditional on all relevant multi-core restrictions, or a gauge-covariant block analogue not requiring one-link alignment; (b) localized background covariance on actual Penrose blocks and stability of the nonflat Wilson Hessian; (c) truncated-cumulant and determinant estimates that force |Ψ_A| to decay in support diameter; (d) bounds uniform across RG scales, spatial volume and h on the fixed physical trajectory; (e) separate Hamiltonian/source reconstruction. None follow from the finite-block identities.
