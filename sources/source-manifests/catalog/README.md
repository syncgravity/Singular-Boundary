# Singular Boundary — historical source search and provenance index

**Archived on 2026-10-30.** The original uploaded archives cover recovered October 11–30 material, and this source-only index records **all 1,281 distinct Git-compatible files** (not the deferred scientific binaries). Original filenames, source archive paths, original source byte SHA-256 and Git blob SHA-1 are recorded in the catalogues.

## Search and citation workflow

1. Use GitHub **Code search** within `syncgravity/singular-boundary` for a theorem name, file basename or symbol; search `path:sources/historical/raw/` to restrict results to original archives.
2. Alternatively browse the per-archive catalogues below. Each entry links to the preserved raw file and gives both SHA-256 and Git SHA-1 for independent verification.
3. Cite a source by its committed repository path plus blob SHA-1. Cite current mathematical status separately in `docs/current/CANONICAL_RESEARCH_STATE_2026-10-30.md`; a historical document is not automatically a validated theorem.
4. Exact duplicate appearances in nested packages are mapped by `SOURCE_MANIFEST.json` in the generated source handoff, not recreated at multiple Git paths. The deduplication is byte-for-byte SHA-256, not a judgement of semantic equivalence.
