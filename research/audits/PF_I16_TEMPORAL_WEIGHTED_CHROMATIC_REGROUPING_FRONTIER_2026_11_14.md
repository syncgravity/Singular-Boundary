# PF-I16 — Temporal weighted chromatic regrouping frontier

**Date:** 2026-11-14

## 1. What the coincident-time theorem changes

The graph-sensitive coincident-time theorem is not limited to equal observation times. Let \(Z_e=(X_e(t))_{t\in\mathbb R}\) be the entire stationary path of link \(e\). The path coordinates \(Z_e\) are independent across links. Every row
\[
Y_i=F_i((X_e(t_i))_{e\in X_i})
\]
is a bounded function of the path coordinates in \(X_i\). Therefore the same connected-component/chromatic-polynomial proof gives, at arbitrary times,
\[
|\kappa(Y_1,\ldots,Y_r)|
\le 2^{r-1}\tau(G_X)\prod_i\|F_i\|_\infty.
\tag{1.1}
\]
This is a useful strengthening of the old coincident-time baseline: the sparse support-tree count is now established for all times, but without temporal decay.

The remaining target is the genuinely stronger estimate
\[
|\kappa(Y_1(t_1),\ldots,Y_r(t_r))|
\le C^r\prod_i\|F_i\|_\infty
\sum_{T\in\mathcal T(G_X)}
\prod_{\{i,j\}\in T}e^{-\Delta_0|t_i-t_j|}.
\tag{1.2}
\]
The distinction is essential. Applying (1.1) to whole paths cannot yield (1.2): it treats each entire path as one independent coordinate and forgets the Markov decay between different observation times on that path.

## 2. Why cross-split QF plus the chromatic theorem is not yet enough

The established path-coupling interpolation proves, for every row split \(J\sqcup K\), a bound of the form
\[
\left|\mathbb E\prod_{i\in J\cup K}Y_i
-\mathbb E\prod_{i\in J}Y_i\,
 \mathbb E\prod_{j\in K}Y_j\right|
\le C^r\prod_i\|F_i\|_\infty
\sum_{i\in J,j\in K}
\mathbf1_{\{X_i\cap X_j\ne\varnothing\}}
e^{-\Delta_0|t_i-t_j|},
\tag{2.1}
\]
with link multiplicity retained when support overlap is not uniformly bounded.

However, an abstract cut estimate such as (2.1) cannot alone imply (1.2). The parity-law obstruction in PF_I16_SUPPORT_TREE_CANCELLATION_BRIDGE_AND_QF_OBSTRUCTION_2026_11_14.md has every proper marginal independent, cut covariance of order epsilon, and full cumulant of order epsilon, while every r-vertex tree product is epsilon^(r-1). This is not a counterexample to the Markov model; it identifies the missing structural input. The weighted proof must use the same-link Markov path law and its ordered-time semigroup expansion, not only its two-side covariance consequence.

## 3. Exact algebraic starting point

For each row subset \(B\), let \(m(B)=\mathbb E\prod_{i\in B}Y_i\). If \(G_X[B]\) has connected components \(C\), independence of disjoint link-path coordinate families gives
\[
m(B)=\prod_{C\in\operatorname{Comp}_{G_X}(B)}m(C).
\tag{3.1}
\]
Consequently the exact chromatic regrouping remains valid at arbitrary times:
\[
\kappa(Y_1,\ldots,Y_r)
=\sum_{\substack{\sigma\text{ partition of }[r]\\
                  \text{each block connected in }G_X}}
[q]\chi_{Q_\sigma}(q)\prod_{C\in\sigma}m(C).
\tag{3.2}
\]
At coincident times, bounding \(|m(C)|\le\prod_{i\in C}\|F_i\|_\infty\), then using deletion–contraction and the tree-cut bijection, proves the support-tree estimate.

For (1.2), that last absolute-value step is too early. It discards the temporal decay inside each \(m(C)\). Nor is it valid to attach one arbitrary temporal bond to each quotient-tree edge: a quotient edge only says that two blocks share at least one link, whereas its temporal factor must be generated by a Markov contraction on that particular shared link.

## 4. The next lemma: a coordinate-preserving temporal forest completion

Expand each link-path joint moment in chronological order using
\[
P_{s_{k+1}-s_k}=\Pi+Q_{s_{k+1}-s_k},
\qquad
\|Q_u\|_{2\to2}\le e^{-\Delta_0u}.
\tag{4.1}
\]
A nonzero term on a link has active Q-intervals with row insertions at their endpoints; stationarity removes an active run with no endpoint insertion. Across links, the resulting row joins are connected for a cumulant term. Every such term therefore contains a connected support multigraph whose edges carry:
- the actual shared link label e;
- the actual pair of row endpoints i,j;
- the Markov interval weight exp(-Delta_0 |t_i-t_j|), or a product of such interval weights along a link-local path.

**Required lemma (not proved here).** Regroup the signed moment–cumulant terms, before taking absolute values, into a family indexed by support spanning trees T in the spanning-tree set of G_X, with total coefficient on each tree bounded by C^r, while preserving for every tree edge an actual shared-link temporal contraction. The completion must preserve link labels and temporal cut profiles. A map that forgets link labels, or an absolute sum over Leonov–Shiryaev slot partitions, is insufficient: the former loses the correct support bond, while the latter has Bell-sized fibers.

A successful proof would yield (1.2), because extra Markov factors are at most one and can be discarded after retaining one factor for each edge of the selected support tree.

## 5. Two focused subproblems

1. **Single-link ordered-time tree cumulant.** For one stationary Markov path with an L2 gap, establish an all-orders bound for arbitrary bounded one-time insertions of the form
   \[
   |\kappa(f_1(X_{t_1}),\ldots,f_m(X_{t_m}))|
   \le C^m\prod_i\|f_i\|_\infty
   \sum_{T\in\mathcal T(K_m)}
   \prod_{\{i,j\}\in T}e^{-\Delta_0|t_i-t_j|}.
   \tag{5.1}
   \]
   This is a natural local building block, not yet shown to be sufficient for arbitrary multi-link rows.

2. **Temporal version of the quotient-graph coefficient.** Replace the hard independence relation used in (3.2) by the ordered-time Pi+Q expansion on each link. Identify a weighted quotient/forest polynomial whose signed coefficient can be bounded by a support-tree sum. The parity obstruction says that the QF cut estimate cannot substitute for this polynomial identity.
