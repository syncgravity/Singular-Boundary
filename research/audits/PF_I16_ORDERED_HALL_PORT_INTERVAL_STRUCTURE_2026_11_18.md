## 1. Ordered ports and matching intervals

At order (n=2s), the port set is the linearly ordered set
\[
P_{2s}=(1<2<\cdots<2s).
\]
A perfect matching (M) is represented as a lexicographically sorted family of unordered pairs
\[
M=\{I_1,\ldots,I_s\},\qquad I_i=(a_i,b_i),\quad a_i<b_i.
\]
Each pair is also regarded as the closed interval (I_i=[a_i,b_i]) on the port line. The intervals are sorted lexicographically by their endpoint pairs. They are not assumed to be disjoint or nested.

The overlap graph (G_M) has one vertex for each matching interval. Its edges are exactly the pairs with **strictly overlapping interiors**:
\[
\{I_i,I_j\}\in E(G_M)
\iff
\max(a_i,a_j)<\min(b_i,b_j).
\]
Sharing only an endpoint is not overlap. A Hall source is
\[
x=(M,\tau),\qquad \tau\in\operatorname{ST}(G_M),
\]
where (operatorname{ST}(G_M)) is the set of spanning trees of this interval-overlap graph. Thus (	au) is not an arbitrary tree on the intervals: every tree edge must be an actual strict-overlap edge.

The root interval is the unique matching interval whose left endpoint is port 1. The root is not eligible for deletion. A non-root leaf is an interval vertex of degree one in (	au), other than the root.

## 2. Explicit six-port example

Take
\[
P_6=(1<2<3<4<5<6),\qquad
M=\{I_1=[1,4],\ I_2=[2,5],\ I_3=[3,6]\}.
\]
The interval order is (I_1<I_2<I_3) lexicographically. Their strict-overlap graph is the triangle:
\[
E(G_M)=\{I_1I_2,\ I_1I_3,\ I_2I_3\}.
\]
Choose the overlap spanning tree
\[
\tau=\{I_1I_2,\ I_2I_3\}.
\]
Its root is (I_1), and its only non-root leaf is (I_3).

Ordered port line and matching arcs:

```text
ports:   1   2   3   4   5   6
         |   |   |   |   |   |
I1:      [---------------]
I2:          [---------------]
I3:              [---------------]

interval-tree tau:
I1  ---  I2  ---  I3
root             non-root leaf
```

The intervals overlap pairwise, but (	au) retains only two of the three overlap edges. This distinction is essential: the source carries a chosen spanning tree of the full overlap graph, not the full overlap graph as its parent/deletion structure.

Deleting the eligible leaf (I_3=[3,6]) removes ports 3 and 6. The retained ordered port list is (1<2<4<5), which is order-compressed to (1<2<3<4). The parent matching and parent overlap tree are
\[
M' = \{[1,3],[2,4]\},\qquad
\tau'=\{[1,3][2,4]\}.
\]
The parent has two ports pairs? It has two matching intervals and four ordered ports; its overlap tree has one edge and one non-root leaf. This parent projection is one of the allowed (pi_\ell(x)); it is not selected by a canonical child-leaf rule.

## 3. Ordered rooted-tree insertion data

Equivalently, root (	au) at (I_0=[1,b_0]). Every non-root interval has a unique parent interval in the rooted tree. A parent-before-child order
\[
(I_{\sigma(1)},\ldots,I_{\sigma(s-1)})
\]
is a linear extension of this rooted-tree partial order: each interval appears after its parent. The target port-spanning trees in the verifier are generated by inserting these intervals in such admissible orders, using the guarded local four-vertex switch at each insertion.

For a marked non-root leaf (J), the marked construction restricts to histories with (J) inserted last. The reverse mark is therefore not merely a label on the final target: it specifies the last interval and the inverse local switch. The inverse final switch recovers the two endpoints of the replaced old edge from the neighbors of the two newly inserted endpoints; deleting (J) and order-compressing the remaining ports gives the parent target (P_J(T)).

The parent projection is genuinely multivalued:
\[
\pi(x)=\{\pi_J(x):J\in L_0(\tau)\},
\]
where (L_0(\tau)) is the set of non-root leaves. The source verifier confirms 1–4 available non-root leaves per ten-port source. A fixed canonical child-leaf selector is not an equivalent replacement.

## 5. Axiom audit after making the source order explicit

* **L1 (port injectivity):** check that all (2s) ordered ports map to distinct accepted (mathbb Z^5) vertices.
* **L2 (matching realization):** check each matched pair's image difference is exactly one signed basis vector. This is a strong axiom; report the first failure rather than silently replacing it by a path.
* **L3 (acceptance):** check vertex windows (W_h) and face triangles (T_{jk,h}) separately.
* **L4 (interval realization):** map each interval's ordered endpoint pair and all ports between them to a connected face-supported subcomplex with an ordered boundary trace. The internal ports are not discarded.
* **L5 (overlap fidelity):** for every strict overlap edge, record the exact common target incidence. Also record non-tree overlap edges: the full graph (G_M) and selected tree (	au) must not be conflated.
* **L6 (parent naturality):** for each eligible leaf (J), compare lift-after-(pi_J) with target deletion-after-lift, including the inverse final switch and port order-compression.
* **L7 (order/orientation):** retain the linear order of all ports and each interval's orientation (a<b), together with directed target-edge orientations.
* **L8 (Hall independence):** freeze the lift constraints before evaluating any Hall neighborhood size, load vector, target congestion, or split-demand flow.

## 6. First implementation cases

1. (n=4): two matching intervals, one overlap-tree edge, exactly one non-root leaf.
2. (n=6): 22 Hall sources in the verified enumeration. Include the explicit example above and all admissible matchings/overlap trees.
3. (n=8): 608 Hall sources; this is the first order with multiple parent/leaf patterns rich enough to expose nontrivial collisions.
4. (n=10): 31,744 Hall sources; retain the existing matching certificate and 12-port retained-grandparent counterexample as independent Hall-side regression data.

For each source, the checker should emit a canonical JSON record containing ordered ports, sorted matching intervals, the full overlap graph, selected rooted spanning tree, eligible reverse marks, parent interval order after compression, and the target-side inverse-switch witness. The ℤ^5 solver consumes these records but must not feed any Hall loads or matching outcomes back into its constraints.

**Conclusion:** the ordered Hall source is now displayed explicitly as a linearly ordered port set, a perfect matching represented by closed intervals, the strict-overlap graph of those intervals, and a chosen rooted spanning tree of that graph. The reverse mark is an eligible non-root leaf interval, and its parent is formed by deleting its two endpoints and order-compressing the remaining ports. This is the exact combinatorial object the labelled incidence morphism must represent.
