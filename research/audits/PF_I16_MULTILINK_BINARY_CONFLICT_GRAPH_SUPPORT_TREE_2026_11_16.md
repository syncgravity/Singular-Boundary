# PF-I16 — Multi-link binary moment expansion and support-tree domination

**Date:** 2026-11-16  
**Status:** exact chromatic expansion proved for symmetric binary link rows; per-configuration support-tree domination proved; global multiplicity bound remains open.

## 1. Model

Let \(E\) be a finite set of independent stationary symmetric two-state Markov links. Link \(e\) is observed at the ordered row times \(t_i\), \(i\in I_e\), and
\[
\mathbb E[X_e(t_j)\mid X_e(t_i)]
=r^e_{ij}X_e(t_i),\qquad
r^e_{ij}=\prod_{k=i}^{j-1}r^e_k\in[0,1].
\]
For each row let
\[
A_i=\prod_{e\in X_i}X_e(t_i),\qquad
I_e=\{i:e\in X_i\}.
\]
The link paths are independent. If any \(|I_e|\) is odd, every partition term in the row cumulant vanishes; assume henceforth all \(|I_e|\) are even.

For an even ordered subset \(B\cap I_e=\{b_1<\cdots<b_{2k}\}\), the link moment is
\[
\mathbb E\prod_{i\in B\cap I_e}X_e(t_i)
=\prod_{h=1}^{k}r^e_{b_{2h-1},b_{2h}}.
\tag{1.1}
\]
Thus each block moment is a product, over links, of canonical consecutive-port pair intervals.

## 2. Exact expansion by link matchings

In the moment-cumulant formula, each partition \(\pi\) contributes one canonical perfect matching on \(B\cap I_e\) for every block \(B\in\pi\) and every link \(e\). Collecting these pairings over all blocks gives, for each link, a perfect matching \(M_e\) of \(I_e\). Its edges are labelled by \(e\) and weighted by \(r^e_{ij}\).

For a family \(M=(M_e)_{e\in E}\), form the row multigraph \(G_M\) on \([R]\) whose edges are all matched pairs, retaining link labels. Let \(\mathcal C(M)\) be its connected components.

A partition can produce exactly this family of matchings iff:

1. every block is a union of components in \(\mathcal C(M)\); and
2. no two same-link pair intervals in a block overlap.

Define the conflict graph \(H_M\) on \(\mathcal C(M)\): two distinct components are adjacent if some intervals from the same link, one in each component, overlap. If two overlapping same-link intervals already lie in one component, regard \(H_M\) as having a loop and set its chromatic polynomial to zero.

Otherwise, valid partitions are exactly the partitions of \(V(H_M)\) into independent color classes. Summing their moment-cumulant Möbius coefficients gives the linear chromatic coefficient
\[
c(H_M)=[q]\chi_{H_M}(q).
\]
Consequently the exact identity is
\[
\boxed{
\kappa(A_1,\ldots,A_R)
=\sum_{M=(M_e)}
c(H_M)
\prod_{e\in E}\prod_{\{i,j\}\in M_e}r^e_{ij}.
}
\tag{2.1}
\]
This is a finite identity. It preserves link labels and is the multi-link analogue of the one-link interval-overlap resummation.

For any graph, \(|c(H)|\) is the number of spanning trees with no broken circuit (Whitney's broken-circuit theorem), hence
\[
|c(H_M)|\le\tau(H_M).
\tag{2.2}
\]
If \(c(H_M)\ne0\), then \(H_M\) is connected. Since each vertex of \(H_M\) is a connected row component of \(G_M\), and each conflict edge comes from overlapping intervals on a common link, the union support graph on rows is connected.

## 3. Per-configuration support-tree domination

Fix a matching family \(M\) with \(c(H_M)\ne0\). For each link \(e\), form the interval-overlap graph of the intervals in \(M_e\). In each connected component \(J\) of this interval graph, the union of its intervals is an interval. Let \(V_J\) be the set of row endpoints of those matched intervals, sorted by time.

Join consecutive vertices of \(V_J\) by edges. Every such edge is a valid support edge: its two row endpoints both carry link \(e\). The total length of this path is
\[
\max V_J-\min V_J
\le \sum_{\{a,b\}\in J}(t_b-t_a),
\tag{3.1}
\]
because the matched intervals in \(J\) have connected union covering the hull.

Take the union of these paths over all links and all interval-overlap components. Its connected components are exactly the equivalence classes generated by the row-pair components and same-link interval overlaps, so connectedness of \(H_M\) makes this union graph connected on all rows. It therefore contains a spanning tree \(T_M\) whose edges all join rows sharing a link.

The total length of \(T_M\) is no greater than the total length of the union paths, which by (3.1) is no greater than the sum of all matched interval lengths. Hence
\[
\prod_{e}\prod_{\{i,j\}\in M_e}r^e_{ij}
\le
\prod_{\{i,j\}\in T_M}W_{ij},
\qquad
W_{ij}:=\max_{e\in X_i\cap X_j}r^e_{ij}.
\tag{3.2}
\]
This proves that every nonzero configuration weight is dominated by at least one support-tree weight.

## 4. The precise remaining multiplicity problem

The per-configuration domination (3.2) does not yet bound the sum of all configurations. Different matching families, and the \(\tau(H_M)\) spanning-tree choices in (2.2), may map to the same row support tree. The missing estimate is a bounded-multiplicity or weighted injection:
\[
\sum_{M}|c(H_M)|
\prod_e\prod_{\{i,j\}\in M_e}r^e_{ij}
\le C_m^R
\sum_{T\in\mathcal T(G_X)}
\prod_{\{i,j\}\in T}W_{ij},
\tag{4.1}
\]
under the row-incidence condition \(|X_i|\le m\), uniformly in the number of links and the port multiplicities.

The exact expansion and (3.2) isolate the combinatorial issue: not connectivity, and not temporal domination term by term, but the multiplicity of configurations over a given support tree. No bound of the form (4.1) is claimed here.

## 5. Finite verification

The companion verifier checks the exact identity (2.1), connectedness of every nonzero conflict coefficient, and construction of a support tree dominating each nonzero configuration weight for several multi-link incidence patterns with exact rational link correlations. These checks validate finite cases only; the proof of (2.1) and the path-domination lemma above are general.

## 6. Scope

This result is restricted to products of centered symmetric binary coordinates on independent Markov links. It does not cover arbitrary bounded link observables or compact-group heat-kernel coordinates. The multiplicity estimate (4.1), the KP activity bound, the interacting-vacuum Poincaré inequality, physical scale-setting, and the continuum Yang–Mills mass gap remain open.
