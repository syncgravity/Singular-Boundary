## 4. Relative deletion adjudication

The source marks settle the earlier graph-5 drop-0 question.

- Graph 5: all 514 retained witnesses have deletion vector `(false,true,true,true)` in support order `0,1,2,3`. Since support 0 corresponds to the root under every root-preserving graph isomorphism, and the source never permits deletion of interval 0, the failed drop-0 collapse is not a source-parent requirement. Every source-eligible deletion (1, 2, or 3) passes.
- Graph 12: all 482 retained witnesses have deletion vector `(true,true,true,true)`. Every source-eligible deletion passes.

For every source parent tree, each parent-tree edge maps to a pair of geometric supports whose intersection is nonempty and point-contractible. Each such pair has reciprocal ordered footprint entries of the same cell type and same cell vertices in the two endpoint support words.

This is a positive finite source/diagram compatibility result. It is stronger than the earlier mark-only audit, but it is still conditional on the root-preserving graph-label correspondence: the source exporter does not identify a particular source record with a particular geometric matched-edge quadruple.

## 5. Source critical-pair checks

For each of the 44 source critical deletion pairs, and under both root-preserving label maps, the audit verifies:

1. The two source deletion orders leave the same reindexed parent tree.
2. Both corresponding geometric single-deletion relative-collapse booleans pass.
3. The remaining two-support intersection is nonempty and point-contractible.
4. The full stored 15-entry intersection table restricts to the same remaining pair in either deletion order.

All 44 source tree diamonds commute, and all corresponding remaining two-support table restrictions are nonempty and point-contractible. The audit emits the source diamond data inside each of the 47,040 witness/source/map rows.

**Important boundary:** this proves source-tree diamond equality and incidence-table restriction coherence. It does not prove that two geometric elementary-collapse sequences commute as maps or that the collapse witnesses are naturally isomorphic. The existing four-support artifact stores collapse booleans, not complete elementary collapse sequences or comparison maps.

## 6. L7b footprint audit and its exact limit

For every retained witness, the four anchored footprint words are present. The audit checks:

- footprint order along each anchored open complementary arc;
- reciprocal footprint entries for each nonempty pair intersection;
- equality of the reciprocal footprint cell types and vertices;
- consistency of each recorded footprint-meeting relation with the actual shared vertices.

The footprint count patterns remain:
- Graph 5: `(3,2,2,1)` for all 514 retained witnesses.
- Graph 12: `(2,3,3,2)` for all 482 retained witnesses.

However, the source exporter contains only port intervals, pairwise overlap graphs, spanning trees, and reverse marks. It prescribes no oriented boundary cycle or ordered multi-footprint word. The geometric artifact exports anchored footprint words, but not a full oriented boundary-cycle certificate matched to source labels. Therefore this audit does **not** close source-prescribed L7b.

## 7. Exact remaining gaps

The audit closes the following finite checks:

- all root-preserving overlap-graph labelings enumerated;
- all 996 retained witness diagrams covered;
- all 47,040 witness/source/map compatibility rows checked;
- all source-legal relative deletions pass;
- all source parent-tree edges land on nonempty contractible geometric pair intersections;
- all 44 source deletion-tree diamonds commute;
- all 44 remaining pair table restrictions are nonempty and contractible;
- all exported target footprint words pass internal reciprocal/order/meet consistency checks.

It does **not** close:

1. **Source-to-target embedding:** an authenticated map from each source interval/port pair/reverse mark to a specific geometric matched-edge vector and support quadruple is absent. The two graph automorphisms are combinatorial possibilities, not a proof of that map.
2. **Full L7b:** no source-prescribed oriented boundary-cycle or multi-footprint word is available in the current source record; the complete oriented cycles are not exported by the current diagram artifact.
3. **Collapse-map coherence:** only relative-collapse booleans are stored; elementary collapse sequences/maps and their commutation around each source diamond are not.
4. **Higher intersections:** source interval records prescribe pairwise overlap only; triple/four-way geometric intersections have no source-side comparison object yet.
5. **Geometric L8:** therefore remains open. The all-orders source port-tree diamond does not supply accepted-face confluence.
6. **All-orders Hall:** not addressed by this finite target audit and remains a separate theorem obligation.

## 8. Next proof task

The next task is not another broad candidate search and not a return to the old Hall allocation attempts. It is to derive and authenticate the source-to-target incidence map from the original PF-I16 `Z^5` geometry, using the actual interval endpoints and accepted matched-edge displacement data. This must determine which of the two root-preserving graph maps is realized, or establish a principled source-derived rule that resolves them.

Once that map exists, extend the target export to include the complete oriented boundary cycles and elementary relative-collapse certificates, then rerun the 44 source diamonds with explicit comparison maps. Only after those checks should the order-eight result be promoted toward geometric L8.

No PR merge is implied by this audit. PR #119 remains a draft research lane pending its CI and source-to-target geometric correspondence.
