# Third-order connected three-face original-link drift

For independent free-Haar SU(2) face holonomies A,B,C define T=Re(ABC), X=Re(A)Re(BC)+Re(C)Re(AB), Y=Re(A)Re(B)Re(C). The established connected cubic vacuum score is S3[ABC]=(191/168480)T-(67/84240)X+(1/1755)Y. For a normalized original-link Killing derivative X_e on a boundary link belonging only to A, the exact product-Haar Gram matrix of (X_eT,X_eX,X_eY) is [[1/16,1/32,1/256],[1/32,5/128,1/128],[1/256,1/128,1/256]]. Thus ||X_e S3[ABC]||²=43523/908336332800 and ||X_e S3[ABC]||_2≈0.0002188951144596898. A non-sharp global supremum upper bound is 37/22464≈0.00164707977208. This treats only the **isolated cubic three-face connected component**, not the full link drift; no all-orders, chain-uniform or λ=1 conclusion is established.
