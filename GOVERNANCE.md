# Evidence governance

**Canonical authority:** this private Git repository at a stated commit, plus verified content-addressed large-file storage. Conversation context is not the record of truth.

- Preserve original filenames, bytes, SHA-256 and provenance; never silently normalize research inputs.
- Label claims as source-asserted, independently verified, conditional, numerical, refuted, open or superseded.
- Every theorem identifies the model, dimension, action, boundary, physical units, limit order and hypotheses.
- Preserve counterexamples and negative findings as dependencies of future proposals.
- Duplicate hashes do not constitute independent evidence.
- Missing historical definitions are open provenance issues; do not substitute reconstructed conjectures.
- Keep separate research tracks: R3-PRISM, R3-IR, R2, Stage 7–26 numerical work, dissertation geometry.
- Do not rerun archived simulations merely because a conversation lacks their details.
- Raw checkpoints are immutable on import. Continuations require a new run identity.
- Repository is private. Never commit credentials.
- At the start of each session read the exact commit, current status, claim ledger and relevant source. At the end record what changed, what was checked, and what remains unresolved.
- **Source discovery is tree-first, never search-only.** Before saying a named file is absent, inspect the complete recursive Git tree for the target branch, record exact paths, and check relevant branch trees and source/archive manifests. Code search may be unavailable or unindexed; an empty search result is not evidence of absence.
- **Read-before-synthesis is mandatory.** Fetch each named source by its exact path and read the complete contents (consecutive line ranges through EOF for long files). Maintain a source ledger with requested name, path, branch/commit, blob ID or content hash, full-read status and role. Never summarize a file from a search excerpt or a remembered synopsis when the source is accessible.
- **Keep absence states distinct.** Record whether a source is absent from a branch, present only in an archive, local-only, Library-only, inaccessible, or still unlocated. Do not substitute a similarly named record or infer the contents of an unlocated file.
- Topic-specific source ledgers are entry points, not immutable truth: revalidate their paths and blob IDs against the current tree before use. The helical-observer register is [HELICAL_OBSERVER_SOURCE_REGISTER_2026-11-11](sources/source-manifests/HELICAL_OBSERVER_SOURCE_REGISTER_2026-11-11.md).
