## Import limitations

This initial tree includes available **small textual originals and extracted text/code** from archived packages (unaltered bytes), but not their binary ZIP, NPZ, tar.gz, or the 352 MB incidence JSON. All are enumerated as `LOCAL_ONLY_NOT_UPLOADED`. They must be imported later through authenticated Git LFS or immutable content-addressed storage, with checksums and no force-push. The entire chat/project historical record has **not** been certified complete.
